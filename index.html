1. Regular Expressions (Regex) Validation

Purpose
Regular Expressions (Regex) are patterns used to validate, search, and manipulate text strings.

What is a Regular Expression?

A Regular Expression is a sequence of characters that defines a search pattern.

/^[A-Za-z0-9_.-]+$/

Regex Used in the Script

if (!/^[A-Za-z0-9_.-]+$/.test(objectStructure)) {
    throw new Error('Invalid objectStructure.');
}

Pattern Breakdown

PatternMeaning
^Start of string
[A-Za-z0-9_.-]Allowed characters
+One or more characters
$End of string

Valid Examples

  • WORKORDER
  • MXWO_OS
  • MXWO.OS
  • MXWO-OS

Invalid Examples

  • WORK ORDER
  • WORKORDER;
  • WORKORDER/TEST
  • WORKORDER@

Security Benefits

  • Validates input before processing
  • Reduces malformed requests
  • Helps prevent injection attacks

Summary

The pattern ^[A-Za-z0-9_.-]+$ permits only letters, numbers, underscores, periods, and hyphens.
